Why this is different

This single-file build is not fake-bloated. It is intentionally dense, cinematic, and feature-rich: multi-layer canvas effects, dynamic filtering, compare tools, spotlight modal, magnetic interactions, parallax, and enough design language to feel like a premium experimental product instead of a website theme.

It can stay as a standalone showpiece, or serve as the raw nucleus for a future production build with real ordering and CMS integration.

This one-file build uses only HTML, CSS, and JavaScript. No frameworks. No dependencies. No placeholders to fake size. The line count is intentionally massive because the system itself is intentionally massive.
